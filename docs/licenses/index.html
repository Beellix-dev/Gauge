Gauge's complete source and build scripts are available at Beellix-dev/Gauge. Source for the unmodified libraries is available from Qt Base 6.8.1, Qt SVG 6.8.1, PySide/Shiboken 6.8.1, CPython 3.11.11 and PyInstaller 6.19.0.

You may modify or replace the LGPL libraries and rebuild Gauge. Follow docs/CONTRIBUTING.md, install your replacement libraries into the build environment and run tools/build.ps1.
