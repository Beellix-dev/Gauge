## Gauge v0.1.1 · 切换账号，保留记录

修复 Codex 切换本地登录后，原账号可能从 Gauge 列表中消失的问题。

### 修复内容

- 自动为识别到的 Codex 本地文件授权保存独立副本。
- 运行时检测本地登录变化，已保存的账号在切换、退出登录和重启后继续保留。
- 按账号身份复用记录，保留自定义名称；写入前检查授权是否发生变化。

### 升级

退出旧版 Gauge，下载 **Gauge-v0.1.1-windows-x64.exe** 并运行。已有账号和设置沿用，无需迁移数据目录。

旧版中已被覆盖、且从未独立保存的账号授权无法恢复，请通过 **+ → Codex** 重新添加一次。平台撤销或过期的授权仍需重新登录。

### 验证与限制

74 项自动化测试通过，包括换号、退出登录、重新加载和并发授权变化；打包程序已通过独立数据目录启动检查。本次未执行真实账号切换。Claude 付费账号在线查询尚未完成端到端人工验证。

此版本仍为预览版，EXE 暂未签名。所用平台的官方 CLI 需另行安装。Codex 实际切换前须退出 Codex 桌面应用及 CLI；Claude 实际登录切换暂不支持。
