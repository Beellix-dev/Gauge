## Gauge v0.1.0 · 额度，一眼就够

首个公开预览版。把 Codex 和 Claude Code 的剩余额度放在桌面一角，让切窗查额度这件小事少打断一次工作。

### 这一版能做什么

- 同时监控多个账号：剩余额度、重置倒计时、会员等级和当前登录状态。
- 自动发现本地有效登录；需要更多账号时，通过官方授权页添加。
- 自由拖动、调整大小、置顶与收进托盘。
- 深海、石墨、月白主题，四种强调色，中英文切换。
- 窗口内设置、自动刷新、开机自启动和可取消的登录流程。
- 实验性的 Codex 登录切换，保留共用的项目、历史与缓存。

### 下载哪个文件

| 文件 | 用途 |
| --- | --- |
| **Gauge-v0.1.0-windows-x64.exe** | 普通用户只需下载这个文件，双击运行 |
| Gauge-v0.1.0-source.zip | 二次开发完整源码、资源、测试和构建脚本 |
| Gauge-v0.1.0-licenses.zip | 随程序附带的第三方许可文本，也可从托盘菜单查看 |
| SHA256SUMS.txt | 下载文件的 SHA-256 校验值 |

支持 Windows 10 / 11 x64，无需 Python。请先安装所用平台的官方 Codex CLI 或 Claude Code，再启动 Gauge。

### 预览版边界

Claude 需要具备 Claude Code 使用权限的订阅授权，免费网页账号和 API Key 额度不适用。Claude 实际登录切换暂不支持。Codex 切换前需要退出桌面应用及 CLI。

自动化测试已通过。Claude 付费账号在线查询和 Codex 实际账号切换尚未完成端到端人工验证；上游接口更新也可能影响查询。EXE 暂未签名。
