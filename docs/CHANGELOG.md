# 更新记录

## 0.1.0 — 2026-09-19

首个公开预览版。

- Codex 每周剩余额度，Claude Code 5 小时与每周剩余额度，以及重置倒计时。
- 本地有效账号自动识别、多账号添加、套餐徽标及当前登录状态。
- 可拖动、缩放、置顶的悬浮窗口，系统托盘与开机自启动。
- 三种主题、四种强调色、透明度调节及中英文切换。
- 窗口内设置、可取消的浏览器授权流程。
- Codex 实际登录切换（实验性）：退出 Codex 后替换授权，继续共用项目与缓存。

### 已知限制

- 支持 Windows x64；依赖所用平台的官方 CLI。
- Claude 需要有效的 Claude Code 订阅授权；暂不支持切换 Claude 实际登录。
- Claude 付费账号在线查询与 Codex 实际账号切换尚未完成端到端人工验证。
- 上游接口变化可能影响额度查询；EXE 暂未签名。
